# Qwen2.5-3B Base FlatQuant 信息论指标分析（20260717）

## 0. 数据来源说明

本报告没有运行新的模型实验。所有"实测值"均取自已有实验记录：

- `docs/report_outlier_distribution_qwen25_base_20260528_zh.md`（SQNR / outlier 指标）
- `docs/report_kl_js_head_alignment_qwen25_base_20260529_zh.md`（JS 散度）
- `docs/svd_flatquant_update_log.md`（PPL、head_proxy_mse、plain_mse）

所有"理论值"由蒙特卡洛数值模拟得到：用与 `diagnostics/qwen25_outlier_distribution.py` 中**完全相同的量化器**（per-row `scale = max/7`，`clamp(round(x/scale), -8, 7)`），作用在同样维度的理想化 iid 分布张量上。模拟样本量约 1.6M/配置，SQNR 估计误差约 ±0.05 dB。

直接实测版本的指标可用新增脚本 `diagnostics/qwen25_info_theory.py` 在服务器上复算。

## 1. 换算约定

- 有效比特：`eff_bits = SQNR_dB / 6.0206`（每比特 6.02 dB）
- 码字熵 `H(Q)`：16 个 INT4 码字的离散香农熵（bits）
- JS 散度：原诊断使用自然对数，最大值 `ln 2 = 0.693147` nats；除以 `ln 2` 换算为 bits（最大 1 bit）

- **iid 高斯混合天花板 ≈ `(6×16.45 + 15.59)/7 = 16.33 dB`**

## 3. 实测值的信息论换算

### 3.1 激活（252 个模块均值）

| 指标 | FP | Baseline | SVD A+B | iid 高斯天花板 |
| --- | ---: | ---: | ---: | ---: |
| `a4_sym_token_sqnr_db` | `6.4133` | `16.3468` | `16.3404` | `16.33` |
| 有效比特（/4 bit） | `1.07` | `2.72` | `2.71` | `2.71` |
| 距天花板 gap | `-9.92 dB` | `+0.02 dB` | `+0.01 dB` | `0` |

**核心结果：baseline FlatQuant 之后，激活的实测 A4 SQNR 与"同一量化器作用在理想 iid 高斯张量上"的理论值之差在 0.02 dB 以内（小于蒙特卡洛误差）。** 即经过 FlatQuant 的激活，对这个量化器而言在边缘分布意义上已经与理想高斯不可区分——"线性可逆变换 + per-token 标量均匀 INT4"这一方法类的率失真上界已经打满。

### 3.2 权重（252 个模块均值）

| 指标 | FP | Baseline | SVD A+B | iid 高斯天花板 | iid 均匀天花板 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `w4_sym_per_out_sqnr_db` | `14.9394` | `19.4555` | `19.4392` | `≈16.3` | `≈22.9` |
| 有效比特（/4 bit） | `2.48` | `3.23` | `3.23` | `2.71` | `3.81` |

权重侧 baseline 已经**超过**高斯天花板约 3.1 dB，说明变换后的权重呈亚高斯（比高斯更平、峰度 < 3），介于高斯与均匀之间。距离均匀分布天花板还有约 3.5 dB，但这部分余量属于"把权重边缘分布进一步推向均匀"，与 SVD 方向加权无关。

### 3.3 分布位移量（JS 散度，换算为 bits）

| 分布 | FP↔Baseline | Baseline↔SVD A+B | 倍数比 |
| --- | ---: | ---: | ---: |
| 激活绝对值 | `0.1919` | `0.00032` | `~600×` |
| token outlier score | `0.9923`（上限 1.0，几乎完全分离） | `0.00064` | `~1550×` |
| 权重绝对值 | `0.1973` | `0.00084` | `~230×` |

FlatQuant 把 token outlier score 的分布推到了与 FP 几乎完全不相交（0.99 bit / 上限 1 bit）；SVD A+B 对分布的扰动比 FlatQuant 小约三个数量级，处于测量噪声水平。

### 3.4 失真再分配的零和证据

固定码率下总失真近似守恒时,加权损失只能"搬运"失真方向。实验数据正是这个形态:

| 层 | 实验 | head_proxy_mse 相对变化 | plain_mse 相对变化 |
| --- | --- | ---: | ---: |
| 34 | 全替换 sigma2_norm | `-3.2%` | `+5.2%` |
| 35 | 全替换 sigma2_norm | `-5.2%` | `+8.4%` |
| 34 | A+B mix linear | `-4.05%` | `+2.52%` |
| 35 | A+B mix linear | `-6.09%` | `+3.71%` |

对应的最终指标变化：WikiText2 PPL `+0.35%`（全替换）/ `+0.09%`（A+B）、C4 `+0.09%` / `+0.01%`——都在噪声量级。

## 4. 解释：为什么 SVD 加权损失在这里没有增益空间

1. **CLT 不动点论证。** FlatQuant 的可逆仿射变换是对上千个近似独立分量的线性混合；根据中心极限定理，线性混合把边缘分布推向高斯，高斯就是"线性变换族"能达到的最平形态（重尾可以被消掉，但不可能被线性变换推成均匀）。实测激活 SQNR 恰好落在 iid 高斯理论值上，说明 FlatQuant 已经到达这个不动点。
2. **量化器类固定 → 率失真上界固定。** 在 per-token 标量均匀 INT4 这个量化器类里，高斯边缘分布对应的失真下界就是 16.3–16.5 dB（2.7 有效比特）。任何只改校准损失、不改量化器、不改变换族的方法（包括 SVD 加权损失）都被这个上界封顶。
3. **SVD 加权损失的可达效果只剩"方向再分配"。** 总失真功率不可再降时，加权损失唯一能做的是把噪声从 lm_head 敏感方向搬到不敏感方向（reverse water-filling 的加权版本）。`head_proxy_mse` 下降 4–6% 与 `plain_mse` 上升 2.5–8% 的同时出现，正是沿失真分配 Pareto 前沿滑动的特征，而 0.2 dB 量级的方向增益不足以在 PPL 上显形。

**结论：现有的 SVD 加权损失系列实验收效甚微，与信息论限制的预测一致——不是实现问题，而是该方法所在的方法类（固定量化器 + 固定线性变换族 + 只改损失权重）在激活侧已无总失真可赚。**

## 5. 界限的适用范围（重要）

这个"天花板"是**标量量化器 + 边缘分布**意义上的，不是绝对香农极限。距离香农率失真极限（24.08 dB / 4.0 有效比特）仍有约 7.7 dB（≈1.3 有效比特）的空间，但只能通过改变量化表示形式获得：

| 途径 | 潜在增益 | 对应方法形态 |
| --- | ---: | --- |
| 非均匀码本（Lloyd-Max / NF4 式） | `+3.9 dB` | 改码字排布，硬件代价高 |
| 熵编码标量量化 | `+6.2 dB` | 变长码，推理不友好 |
| 利用跨通道相关性（矢量量化 / 低秩） | `+7.7 dB` 起 | **SVDQuant 式低秩残差分支、VQ** |

其中第三条是 SVD 真正可能有用的位置：标量量化器无论如何校准都吃不到跨通道互信息；如果变换后激活仍有显著线性相关（Kronecker 结构的变换不做全维白化，大概率有残留），那部分冗余只能靠**改变表示**（如 W16 低秩分支吸收主方向 + INT4 量化残差，即 SVDQuant 路线）来利用，而不是靠改损失权重。

## 6. 可证伪的验证实验

`diagnostics/qwen25_info_theory.py` 直接测量（fp / baseline / svd 三态、逐模块）：

1. `gap_to_gauss_db`：实测 SQNR 减去同维度 iid 高斯天花板 → 预测 baseline 激活全线 ≈ 0；
2. `a4_code_entropy_bits` 与 `kurtosis_raw` → 预测激活码字熵 ≈ 3.0 bits、峰度 ≈ 3（高斯）；权重峰度 < 3（亚高斯）；
3. 代表性模块的 `total_corr_bits_per_dim`（通道相关矩阵的高斯总相关，bits/维）与 `erank_ratio` → 判定跨通道剩余冗余量：
   - 若 TC 显著大于 0（如 > 0.3 bits/维），说明信息论余量在跨通道维度，支持转向 SVDQuant 式低秩残差 / 分组矢量量化；
   - 若 TC 也趋近 0，则 W4A4 当前表示已真正饱和，SVD 线应收官转向。
